# Glossary

**ARES** — Framework for RAG-oriented evaluation workflows (Ch 7)
**Artifact Lineage** — Trace of relationships between code, data, models, and deployments (Ch 12)
**Asynchronous Inference** — Non-blocking inference mode for longer-running jobs (Ch 10)
**Batch Transform** — Offline inference over large datasets (Ch 10)
**CDC (Change Data Capture)** — Incremental synchronization mechanism between storage layers (Ch 4)
**Chat Template** — Canonical message formatting scheme for chat model training/inference (Ch 5)
**CI/CD/CT** — Continuous integration, deployment, and training automation for ML/LLM systems (Ch 11)
**Continuous Batching** — Dynamic request batching for higher serving throughput (Ch 8)
**Data Decontamination** — Removal of benchmark leakage and unsafe overlap from training corpora (Ch 5)
**DPO (Direct Preference Optimization)** — Preference-based model alignment method (Ch 6)
**Embedding** — Dense vector representation of text semantics (Ch 4)
**Experiment Tracking** — Structured logging of run parameters, metrics, and artifacts (Ch 12)
**Feature Pipeline** — Workflow that builds reusable model/retrieval features from raw data (Ch 1, Ch 4)
**FTI Architecture** — Separation into Feature, Training, and Inference pipelines (Ch 1)
**Guardrails** — Runtime and policy controls that constrain unsafe or low-quality model behavior (Ch 11)
**Inference Pipeline** — Runtime processing path from user request to model response (Ch 1, Ch 9)
**Instruction Dataset** — Curated supervised data of prompts and target responses (Ch 5)
**KV Cache** — Reuse of attention key-value states to accelerate decoding (Ch 8)
**LLM Twin** — Domain/persona-specific LLM system emulating target style and expertise (Ch 1)
**LLMOps** — Operational discipline for LLM systems, extending MLOps with feedback and prompt controls (Ch 11)
**LoRA** — Parameter-efficient fine-tuning using low-rank adapters (Ch 5)
**MLOps** — Practices and tooling for reliable machine learning lifecycle management (Ch 11)
**MVP** — Minimum viable product focused on smallest meaningful user value (Ch 1)
**Online Inference** — Synchronous low-latency serving mode (Ch 10)
**OVM** — Operational mapping abstraction in the RAG feature implementation (Ch 4)
**PEFT** — Parameter-efficient fine-tuning family of adaptation methods (Ch 5)
**Preference Dataset** — Pairwise or ranked examples used for alignment training (Ch 6)
**Prompt Monitoring** — Observability over prompt/response patterns in production (Ch 11)
**Qdrant** — Vector database used for semantic retrieval storage and querying (Ch 2)
**QLoRA** — Quantization-aware low-rank fine-tuning approach (Ch 5)
**Query Expansion** — Retrieval pre-processing that broadens search intent coverage (Ch 9)
**RAG (Retrieval-Augmented Generation)** — Generation pattern grounded in external retrieved context (Ch 4)
**Ragas** — Framework for evaluating RAG answer quality and grounding (Ch 7)
**Reranking** — Post-retrieval candidate ordering for improved relevance (Ch 9)
**RLHF** — Reinforcement learning from human feedback for behavior alignment (Ch 6)
**Self-querying** — Model-assisted generation of structured retrieval constraints (Ch 9)
**SFT (Supervised Fine-Tuning)** — Supervised adaptation process on curated instruction data (Ch 5)
**Tensor Parallelism** — Distribution of tensor computations across hardware devices (Ch 8)
**Training Pipeline** — Workflow for producing tuned model checkpoints from datasets (Ch 1)
**Vector Index** — Data structure for efficient nearest-neighbor semantic search (Ch 4)
**ZenML** — Pipeline orchestration platform with artifact and metadata handling (Ch 2)
