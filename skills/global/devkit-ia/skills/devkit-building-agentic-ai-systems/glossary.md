# Glossary

**Action trace** — ordered record of decisions, tool calls, and outputs used to explain behavior (Ch 2, Ch 8).
**Agent policy** — executable rules defining what an agent may do and when to stop (Ch 2, Ch 7).
**Bounded autonomy** — constrained execution model limited by safety and governance boundaries (Ch 2, Ch 9).
**Confidence signaling** — explicit quality indicator attached to outputs and decisions (Ch 8).
**Constraint envelope** — set of policy, risk, and cost limits for execution (Ch 1, Ch 7).
**Coordinator** — role that decomposes objectives and routes work to workers (Ch 6).
**Delegator** — role that assigns specialized subtasks and validates outcomes (Ch 6).
**Evaluation rubric** — measurable acceptance criteria applied to outputs (Ch 7).
**Fallback path** — pre-planned alternative route when tools or assumptions fail (Ch 5, Ch 7).
**Guardrail** — preventive or detective control that blocks unsafe behavior (Ch 9).
**Introspection** — internal review of chain quality, assumptions, and uncertainty (Ch 4).
**Long-term memory** — durable store for reusable context across sessions (Ch 3).
**Planner** — component that converts goals into executable steps (Ch 5).
**Reflection loop** — repeated assess-and-revise cycle during execution (Ch 4).
**Role contract** — interface of responsibilities and acceptance criteria between agent roles (Ch 6).
**Tool adapter** — boundary layer that normalizes access to external APIs or systems (Ch 3, Ch 5).
